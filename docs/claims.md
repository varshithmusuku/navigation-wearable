# What you can and cannot claim (keep README, resume and report consistent)

| Say this | Not this (yet) |
|---|---|
| "Simulated an ESP32-based 3-sensor navigation wearable in Wokwi" | "Built a working wearable" |
| "LEDs act as visual proxies for three directional vibration outputs" | "Tested three vibration motors" |
| "Implemented an adaptive-gain feedback loop (UFFL) based on close-event timing" | "UFFL improves user experience" / "adapts to walking cadence" (it uses close-event timing as a proxy, and no user trials exist) |
| "Adjusts feedback intensity by mode and event rate" | "Adapts alert distance" (distance thresholds are fixed per mode; only intensity is scaled) |
| "Enclosure designed" only after a Tinkercad/STL file exists | "3D-printed prototype" |
| "Low-cost" only after BOM prices are filled | "Costs under X rupees" without a BOM |
